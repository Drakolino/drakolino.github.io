I.Lo que hago, sin jerga

Tres servicios. Cada uno termina en algo que puedes abrir el lunes por la mañana y usar.

01 / Power BI

Dashboards que responden preguntas

Ventas, inventario, márgenes, clientes. Diseñados alrededor de las tres preguntas que te haces cada semana, no de todos los gráficos posibles.

Ideal si hoy armas el reporte a mano cada viernes.

02 / Excel · SQL

Limpieza y conciliación de datos

Duplicados, códigos que no cuadran, sistemas que no se hablan. Encuentro dónde se rompe el número y dejo un proceso para que no vuelva a pasar.

Ideal si tus totales no coinciden entre sistemas.

03 / Python · KPIs

Métricas que se pueden defender

Definimos juntos qué se mide y cómo. Reportes automatizados con definiciones escritas, para que nadie discuta el número — sólo qué hacer con él.

Ideal si cada área calcula “ventas” distinto.

III.Cómo trabajamos

  1. 01

    Diagnóstico

    Una llamada para entender qué decisión quieres tomar y qué datos tienes hoy.

  2. 02

    Datos en orden

    Reviso, limpio y concilio las fuentes. Te digo qué encontré antes de construir nada.

  3. 03

    Construcción

    Avances cortos y revisables. Ajustamos sobre algo real, no sobre un documento.

  4. 04

    Entrega y manual

    Te quedas con el archivo, las definiciones de cada métrica y una sesión para usarlo.
